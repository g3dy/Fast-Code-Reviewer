# Fast-Code-Reviewer
# An AI powered hand-free developer assistant built in python. Its designed for anyone who wants to get quick debug while coding.
By pressing a trigger, the script instantly grabs a visual snapshot of your workspace, records your spoken question, and uses Google-Gemini-2.5-Flash to analyze the context simultaneously. It then speaks the fixed code and explanation using text-to-speech(TTS).
